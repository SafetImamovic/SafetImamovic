## About Me

I'm a Master's student in Software Engineering from Bosnia and Herzegovina, particularly interested in **computer graphics**, **systems programming**, and **mathematics**.

- 🦀 Building graphics and systems projects primarily in **Rust**
- 🎨 Exploring real-time rendering, WebGPU, and GPU architecture
- 🚀 Founder of [EngineCV](https://github.com/enginecv)
- 🎮 Founder of [The Fourth Process](https://github.com/The-Fourth-Process)
- 🧠 Interested in building engines, tools, and complex systems from scratch
- 💬 Ask me about Rust, WebGPU, rendering, or software architecture
